# GPS / LED — быстрые тумблеры для пульта DJI RC 2

Мини-приложение для пульта **DJI RC 2**: переключает несколько параметров полётного
контроллера дрона прямо во время работы DJI Fly, через плавающее меню поверх неё.

## Что умеет

- **GPS** — вкл / выкл
- **Передние LED** — вкл / выкл
- **Режим полёта** — ATTI / Cine
- **Плавающее меню**: маленькая кнопка-ручка `≡` поверх DJI Fly. Тумблеры срабатывают,
  не сворачивая Fly и не прерывая полётную сессию.
- Найденные параметры **запоминаются для каждого дрона отдельно** — при следующем
  запуске с тем же бортом настройка не повторяется.
- **Обновление внутри приложения**: «?» → «Проверить обновление» скачает и поставит
  свежую версию поверх текущей, настройки при этом сохраняются.

## Совместимость

Пульт — **DJI RC 2**. На других пультах не проверялось.

| Статус | Модели |
| --- | --- |
| **Проверено на живом дроне** | Mini 4 Pro, Mini 5 Pro, Lito X1, Mavic 4 Pro, Neo, Avata 360 |
| **Есть в таблице, дрон определяется, поиск не подтверждён** | Neo 2, Flip, Air 3, Air 3S |
| **Есть в таблице, вживую не встречались** | Mini 3 Pro, Air 2S, Mavic 3, Mavic 3 Pro |

Список **не закрытый**. Если модели нет в таблице, приложение всё равно ищет параметры
по имени — просто дольше, до нескольких минут. В любом случае (получилось или нет) стоит
нажать **«?» → «Отправить диагностику»**: модель попадёт во встроенную таблицу следующей
версии, и дальше у всех она будет определяться за секунды.

## Первый запуск

1. **Разрешить или запретить отправку диагностики.** Приложение спрашивает один раз;
   решение можно изменить в любой момент — кнопка **«?»** вверху.
2. **Остановить DJI Fly.** Приложение само откроет нужный системный экран — там нажми
   «Остановить» и вернись назад.
3. **Включить дрон** и дождаться связи с пультом.
4. **Дождаться поиска параметров.** Обычно это несколько секунд; на незнакомой модели —
   до нескольких минут.
5. **Разрешить показ поверх других приложений**, если хочется плавающее меню. Без него
   тумблеры работают прямо в приложении.

Дальше можно запускать DJI Fly и пользоваться ручкой `≡`.

При повторном запуске с тем же дроном шаги 2–4 пропускаются.

## Как приложение находит параметры

У каждой модели и версии прошивки свой набор параметров, и **один и тот же номер на
разных дронах означает разные вещи**. Поэтому приложение никогда не пишет «вслепую по
номеру» — оно ищет параметр **по имени** и обязательно сверяет имя с бортом.

1. **Спрашивает у дрона отпечаток набора параметров** — контрольную сумму и количество.
   Это «паспорт» конкретной модели и версии прошивки.
2. **Ищет этот паспорт во встроенной таблице моделей.** Точное совпадение — номера
   параметров известны сразу, поиск занимает секунды.
3. **Если прошивка новее таблицы** — сверяет по кодовому имени борта и по ближайшему
   количеству параметров.
4. **Если модель всё ещё не опознана** — читает с дрона несколько имён в заранее
   выбранных местах и определяет модель по «отпечатку» содержимого.
5. **Проверяет каждый найденный номер живьём.** Спрашивает у дрона имя параметра под этим
   номером и сравнивает с ожидаемым. **Не совпало — номер не принимается**, ничего не
   записывается.
6. **Если имя не совпало**, пробует по очереди:
   - номера этого же параметра от других моделей;
   - соседние номера вокруг известных — при обновлении прошивки параметр обычно
     сдвигается недалеко;
   - полный перебор всей таблицы — крайний случай, это долго.
7. **Сохраняет найденное для этой прошивки.** В следующий раз поиск не нужен.

Если автоматика ошиблась или не нашла, на экране результата можно **вписать номер
вручную** — он тоже будет проверен по имени, и неверный не примется.

## Почему для поиска нужно остановить DJI Fly

Во время поиска приложение **читает** данные с дрона по тому же каналу, который занимает
DJI Fly, и вдвоём они друг другу мешают. Поэтому настройка делается один раз при
закрытой DJI Fly.

Сами тумблеры ничего не читают — они только отправляют команду, поэтому спокойно
работают при запущенной DJI Fly.

## Если что-то не работает

Нажми **«?»** вверху экрана:

- **Версия** — если сборке много месяцев, скорее всего есть новее.
- **Проверить обновление** — сравнит с последним релизом и предложит установить.
- **Дрон** — что именно приложение определило.
- **Показать журнал** — подробности последней попытки.
- **Отправить диагностику разработчику** — перед отправкой видно, что именно уходит;
  можно вместо отправки скопировать текст и передать вручную.

Если в первом шаге ты разрешил отправку отчётов, приложение **само пришлёт отчёт об
ошибке**, когда упадёт (отправка происходит при следующем запуске). Выключить — тем же
переключателем в «?»; тогда уже сохранённый отчёт удаляется неотправленным.

## Безопасность

Параметры меняются на живом дроне. Делай это **на земле, когда дрон стоит в покое**.
