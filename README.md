# dji_gpsoff — быстрые тумблеры GPS / LED для DJI RC 2

Мини-приложение для пульта **DJI RC 2** (rc331, Android 11): два быстрых
переключателя — **GPS** (`gps_enable`) и **передние LED** (`forearm_led_ctrl`) —
которыми можно управлять **без остановки DJI Fly**, через плавающее overlay-меню
поверх неё. Пакет — `com.djiquick`. Тёмная тема в стиле DJI Fly, ландшафт.

## Как это работает

У борта нет своего USB/Wi-Fi — приложение говорит с полётным контроллером по
протоколу **DUML** через loopback-сокеты пульта (`127.0.0.1:40008` на запись,
`40007` на чтение), src=0x02, dst=0x03 (FLYC), cmd_set `0x03`.

Первый запуск ведёт пошаговый мастер:

1. **Остановить DJI Fly** — приложение показывает, куда нажать, и открывает системный
   экран «О приложении» → «Остановить» (kill из untrusted-приложения на этом железе
   невозможен, стоп жмёт пользователь).
2. **Включить дрон и подключиться.**
3. Приложение **само находит индексы** двух параметров по имени через `get_info`
   (`0xE1`) — не вслепую по индексу, а с проверкой имени с борта, — и сохраняет их
   для этой прошивки (ключ = CRC таблицы параметров).
4. Поднимается **overlay-меню** (GPS on/off, LED on/off). Запись — «слепая» на 40008
   без постоянного reader'а, поэтому оверлей **сосуществует** с работающей DJI Fly.

При следующем запуске с тем же дроном мастер пропускается — сразу overlay.

> **Важно:** детект (чтение на 40007) делать **только с остановленной DJI Fly** —
> одновременный DUML-клиент и Fly конфликтуют на роутере (шторм Broken pipe, Fly
> падает). Overlay пишет на 40008 без reader'а и Fly не трогает.

## Сборка (без gradle)

`build.ps1` — aapt2 link → javac → d8 → zipalign → apksigner. Нужен Android SDK
(`build-tools`, `android.jar` из platform-34), подпись общим debug-keystore.

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Результат — `build/QuickToggle.apk` (min-sdk 24, target-sdk 30, arm64).

`build-test.ps1` собирает вариант под чистым `applicationId com.djiquicktest`
(`AndroidManifest.test.xml`) для проверки обычной установки из APK.

## Деплой на пульт

`adb` на RC недоступен. Деплой — по **MTP** во внутренний накопитель, установка —
через системный shell (`com.dpad.fuli`) по telnet:

```bash
./deploy.sh --build     # собрать, запушить по MTP, pm install -r -g по telnet
```

Драйвер shell — `tools/rc2sh.py` (telnet 2323). Ручной путь (тап по APK на пульте)
остаётся запасным.

## Безопасность / легальность

Запись параметров опасна при активном управлении — делать **на земле, дрон в покое**.
Overlay задуман именно для этого: быстрое переключение GPS/LED без риска для активной
Fly-сессии. Отключение GPS и снятие ограничений во многих юрисдикциях нарушает правила
эксплуатации БВС — всё предназначено для исследования собственного устройства и
интероперабельности.

## Что НЕ входит в репозиторий

- `build/`, `build-test/`, `*.apk` — артефакты сборки.
- `assets/telemetry.b64` — приватный секрет диагностической телеметрии
  (XOR+Base64 обфускация endpoint'а). Без него телеметрия — no-op; в коде остаётся
  только XOR-ключ, который сам по себе ничего не раскрывает.
