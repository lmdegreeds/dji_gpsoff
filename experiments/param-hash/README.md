# Тест находки: чтение/запись параметра по хешу имени (0x03 / 0xF8·0xF9)

Ветка `feat/param-hash-f8f9`. Экспериментальный стенд — **не часть сборки приложения**.

## Суть находки

В обоих сторонних проектах параметр FLYC пишется/читается **по 4-байтовому хешу
имени**, а не по индексу:

| проект | операция | cmd_set | cmd_id | payload |
|---|---|---|---|---|
| FreeFCC | write LED `forearm_led_ctrl` | `0x03` | `0xF9` (249) | `a2 59 ce ed` + `ef`/`00` |
| FreeFCC | write `max_height_0` = 500 | `0x03` | `0xF9` | `8a 23 71 03` + `f4 01` |
| SkylabFCCfree | read GPS-параметр | `0x03` | `0xF8` (248) | `82 95 42 c5` |

**Если восстановить алгоритм хеша — индексы не нужны совсем**: не нужна таблица
моделей, `get_info`, поиск, чтение на 40007 и остановка DJI Fly. Пакет
самодостаточен: `<hash:4> [+ value]`.

## Что в этой папке

| файл | что |
|---|---|
| `duml.py` | byte-verified DUML v1 framing + CRC-таблицы (копия из `analisys_1/`) |
| `hashparam.py` | **живой тест транспорта**: LED вкл/выкл по хешу, generic read/write по хешу, сверка с индексным путём |
| `recover_hash.py` | попытка восстановить алгоритм хеша (словарь + аффинный взлом) |
| `FINDINGS.md` | результаты этой сессии + якоря для дизассемблирования |

## Как запускать

Всё — на пульте **DJI RC 2** (DUML-прокси слушает loopback). По умолчанию
**dry-run** (только печать кадров), реально слать — флаг `--send`.

```bash
python hashparam.py selftest              # проверка framing без железа
python hashparam.py led on                # dry-run: показать кадр LED-ON
python hashparam.py probe --send          # LED ON → 2с → OFF (визуальный тест 0xF9)
python hashparam.py read 829542c5 --send  # чтение по хешу (0x03/0xF8)
python hashparam.py xcheck --send         # тот же LED через индекс (0x03/0xE3 idx23) — сверка
```

Транспорт повторяет рабочую модель FreeFCC на RC2: **один кадр на TCP-соединение**
(open → write → read ACK → close). Порт автоопределяется (40009 → 40007 → 40008);
LED-запись по умолчанию оборачивается внешним конвертом `55 CC 30 75 + LE-len`
(как в FreeFCC для 40007). Переопределить: `--port`, `--wrapper`/`--no-wrapper`.

## Статус

- ✅ **Транспорт воспроизведён**: `hashparam.py selftest` собирает LED-кадр
  байт-в-байт как FreeFCC (`…40 03 f9 a2 59 ce ed ef…`). Готово к проверке на железе.
- ❌ **Алгоритм хеша НЕ восстановлен.** Ни словарь из ~17 стандартных функций по
  1787 именам, ни алгебраический взлом Horner-семейства по двум опорным парам не
  дали совпадений (детали и якоря — в `FINDINGS.md`). Это подтверждает пометку
  находки: алгоритм придётся доставать из `libdrone_hacks_lib.so`.

## Осторожно

Запись параметров опасна при активном управлении. Тестировать: дрон на земле, в
покое, DJI Fly закрыта (см. §4–5 корневого `CLAUDE.md`). LED — самый безопасный
параметр для проверки транспорта (визуальный отклик, ничего не ломает).
